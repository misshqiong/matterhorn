# Claude Code over MCP

Run setup from the Claude Code project:

```console
mh setup claude-code
mh setup claude-code --url http://127.0.0.1:8000
```

The first command generates the embedded stdio shape; the second generates the
hub URL shape plus a `Stop` hook for per-turn delivery. Both merge
`SessionStart` and `SessionEnd` hooks. Generated hook commands use the absolute
path of the running `mh`, so rerun setup after moving or replacing the
environment.

The checked-in root `.mcp.json` and `.claude/settings.json` are the generated
embedded sample. `hub/.mcp.json` and `hub/.claude/settings.json` are the
generated hub sample. They were regenerated by the commands above; only
machine-specific absolute paths were normalized to `/absolute/path/to/...`.
The project Skill is optional guidance and is not written by setup.

Verify both generated shapes and the optional Skill from the repository root:

```console
$ .venv/bin/python examples/claude-code/verify.py
embedded=stdio command=mh mcp hooks=SessionStart,SessionEnd
hub=http url=http://127.0.0.1:8000/mcp hooks=SessionStart,SessionEnd,Stop
skill=.claude/skills/matterhorn/SKILL.md
tools=9
```

The nine tools are `add_messages`, `add_cards`, `add_records`, `query_current`,
`query_timeline`, `query_at`, `query_by_person`, `list_matters`, and `correct`.
Configure the Console AI panel or a write-side provider before real Message or
Record extraction; deterministic reads need no model.
